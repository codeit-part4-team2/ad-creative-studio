# 자연스러운 코믹 대본과 단순 자막 디자인

## 1. 목적

러시아워 쇼츠의 정확한 한국어 TTS는 유지하면서, 말투는 실제 광고처럼 자연스럽게
다듬고 문장의 내용에서 무표정한 웃음이 나오게 한다. 생성 이미지에는 문자를 넣지
않으며, 화면에 보이는 문자는 렌더러가 추가하는 자막만 허용한다. 자막은 그림자나
박스 없이 단순하게 표시하되 밝은 배경에서도 읽혀야 한다.

## 2. 범위

- `deadpan-ai-v1`의 네 장면 구조는 유지한다.
- MeloTTS 모델, 음성 프리셋, 속도와 발음 사전은 변경하지 않는다.
- 모델 서버 `/infer` 계약과 추가 이미지 2회 순차 호출 구조는 변경하지 않는다.
- YouTube 승인·예약 게시 흐름은 변경하지 않는다.
- 자동 OCR 의존성은 이번 변경에 추가하지 않는다.

## 3. 코믹 대본

대본은 외부 LLM 없이 검증된 템플릿 묶음에서 결정적으로 선택한다. 정규화한 상품명과
시간대의 SHA-256 값을 템플릿 개수로 나눈 인덱스를 사용하므로 프로세스나 운영체제가
달라도 동일한 상품과 시간대는 동일한 대본을 받는다. 상품이 달라지면 템플릿이 달라질
수 있다. 이를 통해 토큰 비용과 사실 환각 없이 반복 노출의 단조로움을 줄인다.
변경된 대본 계약은 `deadpan-ai-v2`로 기록해 기존 렌더 결과와 구분한다.

네 장면은 다음 책임을 갖는다.

1. `INTRO`: 상품을 자연스럽게 짧게 소개한다.
2. `SELF_AWARE`: AI 광고임을 무표정하게 인식하는 문장으로 웃음을 만든다.
3. `BENEFIT`: 저장된 첫 번째 소구점만 사실 그대로 전달한다.
4. `CTA`: 과장하지 않는 짧은 확인 요청과 건조한 후속 문장을 사용한다.

문장은 존댓말을 유지하며, 억지 오발음·맞춤법 오류·검증되지 않은 성능·가격·할인
주장을 사용하지 않는다. `display_text`와 `spoken_text`는 기존 발음 사전을 통해
분리하고, 영문·숫자·브랜드 발음 검수 게이트를 유지한다.

대표 예시는 다음과 같다.

> 휴대용 선풍기, 출근길에 짧게 소개할게요.
> 광고라서 칭찬은 해야 합니다. 과장은 안 하겠습니다.
> 눈여겨볼 점은 USB-C 충전이에요.
> 필요하셨다면 확인해 보세요. 저는 계속 여기 있겠습니다.

모든 템플릿은 기존 2줄 자막 안전 영역에 들어가야 하며, TTS와 무음 구간을 합친
예상 영상 길이가 10~15초를 벗어나면 렌더 전에 실패한다.

## 4. 이미지 내 문자 배제

쇼츠용 장면 프롬프트는 배경 전용임을 반복해서 명시하고 다음 요소를 금지한다.

- 읽을 수 있는 문자, 가짜 문자, 글자 형태의 무늬
- 숫자, 가격표, 할인표, 메뉴판, 간판, 포스터
- 제품 라벨을 흉내 낸 문구, UI 화면, 로고, 워터마크, 서명
- 타이포그래피가 들어간 장식물이나 패키지

프롬프트만으로 생성형 모델의 문자를 완전히 보장할 수 없으므로, 이미지 안에 문자가
보이면 `product_preserved=true`와 무관하게 승인하지 않고 재생성한다. 이 기준을
운영 체크리스트와 회귀 테스트에 추가한다. 반복 발생률이 높아질 때만 OCR 기반 자동
차단을 별도 변경으로 검토한다.

## 5. 자막 디자인과 가독성

자막은 다음 단일 스타일을 사용한다.

- 채우기: 흰색 `#F8FAFC`
- 외곽선: 어두운 남색 `#121826`, 2px
- 그림자와 Gaussian blur: 없음
- 검은색 또는 반투명 배경 박스: 없음
- 톤별 강조색과 부분 색상 강조: 없음
- 배치: 기존 상단/하단 2줄 안전 영역 유지

흰색이나 매우 밝은 배경에서는 어두운 2px 외곽선이 글자 경계를 만들고, 어두운
배경에서는 흰색 채우기가 대비를 만든다. 스타일을 배경마다 바꾸지 않아 장면 간
디자인 일관성을 유지한다.

## 6. 검증

자동 테스트는 다음을 확인한다.

- 대본이 자연스러운 존댓말과 하나의 `SELF_AWARE` 문장을 사용한다.
- 대본이 저장되지 않은 할인·가격·성능을 만들지 않는다.
- 상품명과 소구점의 표시/발음 분리가 유지된다.
- 이미지 프롬프트가 문자·숫자·간판·가격표·UI·워터마크를 모두 금지한다.
- 자막 스타일이 흰색 채우기, 2px 외곽선이며 그림자와 강조색을 사용하지 않는다.
- 흰색, 밝은 회색, 어두운색 배경 렌더에서 글자 채우기와 외곽선 픽셀이 모두 존재한다.
- 전체 테스트, FFmpeg 통합 테스트와 GitHub CI가 통과한다.

사람 검수는 실제 생성 영상에서 다음을 확인한다.

- TTS 발음이 정확하고 문장 호흡이 자연스러운가.
- 이미지 안에 생성된 문자가 없고 자막만 보이는가.
- 밝은 배경과 어두운 배경 모두 자막이 읽히는가.
- 자막에 그림자·박스·색상 강조가 남아 있지 않은가.
