# 러시아워 쇼츠 TTS 여유 시간 디자인

## 문제와 근거

PR #26 반영 후 L4 E2E에서 실제 MeloTTS 발화는 14.365초였고, 기존 최소 무음
1.600초를 더한 예상 영상 길이는 15.965초였다. 허용 상한 15.05초보다 0.915초
길어 FFmpeg 실행 전에 정상적으로 차단됐다. 장면별 길이는 intro 2.967초,
self-aware 4.210초, benefit 3.362초, CTA 3.826초다.

PR #26의 시간 계산과 검증은 정확하다. 남은 원인은 상품 사실과 무관한 정적
self-aware/CTA 문장이 실제 MeloTTS에서 8.036초를 차지하는 것이다.

## 선택한 변경

MeloTTS 속도 0.94, 15초 제한, 장면 무음, intro와 benefit 문장은 유지한다.
self-aware와 CTA 템플릿만 더 짧게 만들고 대본 버전을 `deadpan-ai-v4`로 올린다.
대본 버전과 실제 문장이 source fingerprint에 포함되므로 이전 v3 작업과 구분된다.

시간대별 문장은 다음과 같다.

| 시간대 | 변형 | SELF_AWARE | CTA |
|---|---:|---|---|
| 출근 | 0 | `광고입니다.` | `보세요. 전 일합니다.` |
| 출근 | 1 | `안 쉽니다. 광고합니다.` | `보세요. 안 늦습니다.` |
| 퇴근 | 0 | `퇴근은 없습니다.` | `보세요. 전 못 갑니다.` |
| 퇴근 | 1 | `광고입니다. 최선입니다.` | `보세요. 전 일합니다.` |

문법과 발음은 자연스럽게 유지하고, 음성 자체를 일부러 틀리게 만들지 않는다.
AI가 광고와 노동 상태를 무표정하게 인식하는 기존 코믹 방향은 유지한다.

## 범위 밖

- TTS 속도 상승 또는 FFmpeg 배속
- 15.05초 상한 완화
- 길이 초과 후 두 번째 TTS 합성
- intro의 상품명 또는 benefit의 첫 번째 소구점 절단
- 렌더러 시간 계산 변경

동적 상품명이나 소구점이 매우 길면 기존 검증이 계속 실패를 차단한다. 이를 자동
축약하는 정책은 상품 사실 손실 가능성이 있어 이번 후속 PR에 포함하지 않는다.

## 검증과 운영 승인

자동 테스트는 네 시간대/변형의 정확한 self-aware와 CTA 문장, `deadpan-ai-v4`,
기존 4장면 순서, 첫 번째 소구점과 발음 사전 계약을 확인한다. 전체 pytest, 변경
파일 Ruff, compileall, pip check, diff check와 CI를 실행한다.

로컬에는 MeloTTS 모델이 없으므로 실제 성공은 확정하지 않는다. PR 반영 후 같은
조건으로 L4 E2E를 다시 실행해 `render_status=completed`, 예상/최종 길이 10~15초,
발음·코믹 타이밍·자막 일치를 사람이 확인한다.
