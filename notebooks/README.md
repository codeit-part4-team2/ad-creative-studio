## ⚠️ 커밋 전 필수 — nbstripout 설치 (최초 1회)

`.ipynb`는 코드 셀 실행 결과(출력)와 실행 횟수까지 파일에 같이 저장됩니다.
그대로 커밋하면 코드가 안 바뀌어도 diff가 지저분해지고, 머지 충돌이 잦아집니다.

이 레포는 `nbstripout`으로 **커밋 시 출력만 자동 제거**(코드는 그대로 유지)하도록 설정돼 있습니다.
클론 직후 딱 한 번만 실행하면 됩니다:

```bash
pip install -e ".[dev]"
nbstripout --install
```

이후로는 평소처럼 노트북을 실행하고 저장한 뒤 `git add`/`git commit`만 하면,
커밋되는 순간 출력이 자동으로 벗겨집니다. 로컬 파일 자체는 그대로 출력이 남아있으니
직접 보면서 작업하는 데는 지장 없습니다.

PR을 열면 CI(`.github/workflows/test.yml`)에서도 출력이 안 지워진 채로 올라온 노트북이
있는지 한 번 더 검증합니다 — 설치를 깜빡해도 PR 단계에서 걸러집니다.
